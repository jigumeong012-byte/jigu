# LifeQuest

기존 프론트엔드와 Java/Spring Boot 백엔드를 연결한 로컬 할 일·성장 관리 웹사이트입니다.

## 실행

프로젝트 폴더의 `실행.cmd`를 더블클릭하거나 다음 명령을 실행하세요.

```powershell
cd "C:\Users\master\Desktop\Java 프로젝트\lifequest"
npm.cmd start
```

접속 주소: http://localhost:8080

## 홈 화면에 설치

배포된 HTTPS 주소를 휴대폰에서 연 뒤 앱으로 설치할 수 있습니다. Android Chrome에서는 브라우저 메뉴의 **앱 설치** 또는 **홈 화면에 추가**, iPhone/iPad Safari에서는 **공유 → 홈 화면에 추가**를 선택하세요. 사이트 하단의 **앱 설치** 버튼에서도 지원 브라우저의 설치 창 또는 기기별 안내를 볼 수 있습니다. 메뉴 이름과 설치 가능 여부는 브라우저에 따라 다릅니다.

설치 후 인터넷에 연결할 수 없으면 오프라인 안내 화면이 표시됩니다. 퀘스트 및 경험치 조회·변경에는 서버 연결이 필요하며, 푸시 알림이나 오프라인 동기화는 제공하지 않습니다. 서버 데이터는 기기 간 공유되지만 메모·체크리스트·프로필과 설정은 각 브라우저나 설치된 앱의 저장소에 따로 보관될 수 있습니다.

JDK 21, MySQL 8.0+, Node.js가 필요합니다. 현재 PC의 설치 경로를 자동으로 찾습니다. Maven은 기존 설치 또는 캐시를 우선 사용하며, 없으면 체크섬을 검증해 내려받습니다. 최초 빌드에는 인터넷 연결이 필요합니다.

Spring Boot가 `dist/`의 화면과 `/api`를 같은 서버에서 제공합니다. 소스를 변경한 뒤에는 서버를 종료하고 다시 실행해 JAR에 반영하세요. 실행 창에서 Ctrl+C를 누르면 웹서버가 종료됩니다. 로컬 MySQL은 계속 실행되며 다음 실행 때 재사용합니다.

`PORT` 환경 변수로 웹서버 포트를 바꿀 수 있습니다. 외부 DB를 사용하려면 `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`를 지정하세요.

## 개발 모드

백엔드를 위 방법으로 실행한 상태에서 별도 터미널에서 `npm.cmd run dev`를 실행하면 http://localhost:5173 에서 프론트엔드 파일 변경을 바로 확인할 수 있습니다. 이 서버는 `/api` 요청을 기본적으로 http://127.0.0.1:8080 으로 전달합니다. 백엔드 포트를 변경했다면 `API_ORIGIN`도 맞춰주세요.

## 데이터와 기능

- MySQL 저장: 퀘스트 제목, 카테고리, 난이도, 보상, 완료 여부, 등록 시각, 사용자 레벨과 경험치.
- 퀘스트 등록·수정·복제·삭제·완료, 카테고리 필터와 정렬을 제공합니다.
- 쉬움 10 / 보통 30 / 어려움 50 XP. 경험치 100마다 레벨이 올라갑니다.
- 완료 보상은 한 번만 지급됩니다. 완료 취소는 지원하지 않으며 완료한 퀘스트의 난이도를 변경할 수 없습니다. 퀘스트를 삭제해도 이미 획득한 경험치는 유지됩니다.
- 브라우저 저장: 메모, 체크리스트, 중요 표시, 일정 라벨, 프로필, 설정. 체크리스트는 추가 XP를 지급하지 않습니다.
- 집중 타이머는 25분이며 탭 내 이동 중 유지됩니다. 새로고침하면 초기화됩니다.
- 성장의 카테고리 집계는 선택 기간에 등록된 퀘스트 중 현재 완료된 항목 기준입니다. 삭제한 퀘스트는 이 집계에서 제외됩니다.

기본 서버는 로컬 PC 전용 단일 사용자(ID 1)입니다. 로그인·회원가입·비밀번호 화면은 브라우저 데모이며 서버 인증이나 사용자별 접근 제어를 제공하지 않습니다. Google/Apple 로그인, 메일·푸시 발송, 회원 탈퇴, 자동 반복 생성은 연결되지 않았습니다. 별도 인증 구현 없이 공개 서버로 배포하는 구성은 아닙니다.

요일별 과거 차트, 레벨 7 예시 기록, 뱃지는 화면에 표시된 미리보기입니다. 실제 레벨·누적 XP·퀘스트 수에는 예시 수치를 더하지 않습니다.

## DB 저장 위치

Windows MySQL의 한글 경로 오류를 피하기 위해 데이터 파일은 `%USERPROFILE%\AppData\Local\LifeQuest\<프로젝트 경로 해시>\mysql-data`에 저장합니다. `LIFEQUEST_DATA_DIR`로 영문 경로를 지정할 수도 있습니다. 같은 데이터 위치를 계속 사용해야 기존 기록이 유지됩니다. 이 PC의 기본 MySQL과 별개로 127.0.0.1:3307을 사용합니다.

프로젝트의 `.local/connection.json`에는 로컬 DB 연결 정보가 있으므로 데이터 파일과 함께 보존하고 외부에 공유하지 마세요. `.local/`, `.tools/`, DB 파일은 Git 추적 대상에서 제외합니다.

## 검증

```powershell
npm.cmd run check
npm.cmd test
npm.cmd run test:all
```

`test:all`은 JS 검사·11개 Node 테스트와 실제 MySQL/임시 HTTP 서버를 사용하는 Java 통합 테스트 6개를 실행합니다. 기본 테스트 DB는 `lifequest_test`로 실제 앱 DB와 분리됩니다. 외부 DB를 사용한다면 별도의 `DB_TEST_URL`을 지정해야 합니다. 통합 테스트는 자신이 만든 사용자와 퀘스트만 정리합니다. Maven만 직접 실행할 때 `DB_TEST_URL`이 없으면 통합 테스트는 건너뜁니다.

수정 내역과 최종 검증은 `검증결과.md`를 확인하세요.
